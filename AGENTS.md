# Publicação

O fluxo obrigatório de publicação deste repositório é `dev → homologacao → main`.

- Envie e valide as alterações em `dev` antes de promover para `homologacao`.
- Aguarde a validação em `homologacao` antes de promover para `main`.
- Preserve o mesmo commit validado nas promoções; não publique diretamente em `main`.
- Não use force push para promover versões.
